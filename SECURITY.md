# Política de seguridad

## Versiones soportadas

| Versión | Soportada |
|---|---|
| 0.3.x | ✅ |
| < 0.3 | ❌ |

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad, **no abras un issue público**.
En su lugar, envía un correo a:

**juani1972@users.noreply.github.com**

Incluye:

- Descripción del problema.
- Pasos para reproducirlo.
- Impacto potencial.
- Sugerencia de mitigación (si la tienes).

## Tiempo de respuesta

- Confirmación de recepción: **48 horas**.
- Evaluación inicial: **7 días**.
- Parche (si procede): **30 días**.

## Alcance

Esta política cubre:

- Código de `app/core/` y `app/pages/`.
- Scripts de despliegue (`Dockerfile`, `docker-compose.yml`).
- Workflows de GitHub Actions.

## Fuera de alcance

- Vulnerabilidades en dependencias de terceros (reporta upstream).
- Problemas derivados del uso de datos de Yahoo Finance.
- Cuestiones de exactitud financiera (no es un proyecto de producción).
